## 🚀 Getting started
1. Accept the GitHub invite sent to your email.
2. LET ME KNOW if you have trouble doing the following.
3. Clone the repo:
   git clone https://github.com/[org-name]/[repo-name].git
4. Create your own branch before making changes:
   git checkout -b your-name/short-description

## 🤝 How to contribute
- Don't push directly to `main`. Open a pull request instead.
- Write clear commit messages (e.g. "Add data cleaning script").
- Put each project in its own folder with a short README inside.
- Never commit passwords, API keys, or personal data.
